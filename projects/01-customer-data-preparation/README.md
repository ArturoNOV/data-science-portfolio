# Customer Data Preparation with Python

**TripleTen Data Science Bootcamp — Sprint 1: Python Basics**

## Project Overview

This introductory Python project focuses on preparing customer data for future business analysis at a fictional retail company, Store 1.

The raw customer records contain formatting inconsistencies and data type issues that must be corrected before the information can be used for customer segmentation, purchasing analysis, and marketing-related tasks.

## Objective

Practice fundamental Python operations by cleaning, validating, transforming, and organizing customer records without using external libraries.

## Tasks Performed

- Cleaned customer names by removing unnecessary whitespace and replacing inconsistent separators.
- Split customer names into separate components.
- Converted customer ages to the appropriate numeric data type.
- Used exception handling to manage invalid age values.
- Sorted customer records by user ID.
- Calculated total spending across product categories.
- Generated formatted customer summaries.
- Reorganized nested customer records into cleaner structures.

## Python Concepts Practiced

- Variables and data types
- Strings and string methods
- Lists and nested lists    
- Indexing
- Type conversion
- Exception handling
- Sorting
- Built-in functions
- f-strings

## Files

- `project.ipynb` — Jupyter Notebook containing the original step-by-step project, explanations, code, and outputs.

## How to Run

No external libraries or datasets are required.

Python script:

python project.py

The notebook can be opened with Jupyter Notebook, JupyterLab, or VS Code.
