# Customer Data Processing and Segmentation with Python

**TripleTen Data Science Bootcamp — Sprint 2: Python Basics (continued)**

## Project Overview

This project continues the customer data work introduced in the previous
Sprint using a fictional retail company, Store 1.

The objective is to move from individual data-cleaning operations toward
reusable processing logic and basic customer analysis. Raw customer records
are cleaned, standardized, processed in bulk, and filtered according to
business criteria.

## Objective

Apply fundamental Python programming concepts to build reusable data-processing
logic and answer basic business questions related to customer behavior,
spending, and segmentation.

## Tasks Performed

- Standardized customer names and converted them into structured components.
- Converted customer ages to the appropriate numeric data type.
- Normalized product categories to lowercase.
- Created a reusable function to clean individual customer records.
- Applied the cleaning function across the complete customer dataset.
- Calculated total customer revenue.
- Identified customers based on age and spending criteria.
- Filtered customers according to purchased product categories.
- Created a reusable function for category-based customer segmentation.

No external libraries or datasets are required.

To run the Python script:

```bash
python project.py
```
