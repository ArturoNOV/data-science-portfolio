The business questions

From operational patterns to statistical evidence

This TripleTen course scenario uses a fictional ride-sharing company called Zuber and taxi activity in Chicago during November 2017.

01 · Operators

Who completed the most trips?

Compare activity across taxi companies using aggregated trip data.

02 · Destinations

Where did passengers go?

Identify neighborhoods with the highest average taxi arrival volumes.

03 · Weather

Do durations differ by weather?

Test the difference in mean duration for Saturday trips from the Loop to O'Hare.

Methodology

Reproducible, transparent analytical workflow

The project preserves the original course analysis and separately documents the local reconstruction. They are not interchangeable datasets.

01 · Gather & prepare

SQL data extraction

Aggregate taxi company activity and destination neighborhoods; isolate relevant Loop-to-O'Hare Saturday trips.

02 · Explore

Python analysis

Use pandas and matplotlib to explore distributions, compare groups, and investigate data quality.

03 · Test & interpret

Statistics

Exclude zero-duration trips, assess variance with Levene's test, and apply an independent two-sample t-test.

~2,013 sMean Saturday trip duration · good weather
~2,427 sMean Saturday trip duration · bad weather
~414 sDifference between group means
Interpretation, not causation.

The original academic analysis reported a p-value of approximately 1.33 × 10⁻¹¹, supporting a statistically significant difference between group means at the 5% level. This is an association in the analyzed sample, not proof that bad weather itself caused the longer trips.

Independent reconstruction

Rebuilding the SQL workflow locally

The original course datasets were not a standalone PostgreSQL database. I separately reconstructed the workflow using public Chicago taxi data and supporting datasets, creating database schemas, ingestion scripts, validation steps, and reproducible SQL queries.

The repository includes a deterministic 100,000-row sample for more practical GitHub reproducibility. The local reconstruction is not an exact copy of the original course database, so locally derived totals and the original academic outputs are not expected to match.

Analytical boundary

Reported statistical results above belong to the original academic analysis. The local PostgreSQL sample is a separate reproducibility resource, not an independent replication of those exact results.
