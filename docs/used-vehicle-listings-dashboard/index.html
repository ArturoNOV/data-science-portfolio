Used Vehicle
Listings Dashboard

Exploring used-vehicle advertisements in the United States through an interactive dashboard that visualizes mileage distributions and the relationship between price and mileage.

PythonpandasStreamlitPlotlyJupyter Notebook
Open live dashboard ↗ View source code ↗
What the application explores

From listings to visual exploration

The application focuses on two straightforward analytical questions. Its charts are exploratory visualizations, not a vehicle-price prediction model.

▥
01 · Histogram

How is mileage distributed?

Generate a Plotly histogram of vehicle odometer readings to examine the mileage distribution.

↗
02 · Scatter plot

How do price and mileage relate?

Optionally display a scatter plot of advertised vehicle prices against odometer readings.

▣
03 · Interaction

How can visitors explore?

Select whether to include the scatter plot, then use the build button to generate the charts.

Methodology and implementation

From CSV to interactive web application

The project includes a supporting exploratory analysis notebook as well as a deployed Streamlit app.

01 · Load

Data with pandas

Load the used-vehicle listings CSV file for exploratory analysis and interactive visualization.

02 · Explore

Plotly charts

Display mileage distributions and inspect the relationship between price and mileage.

03 · Publish

Streamlit and Render

Expose the charts in a Streamlit interface and make the app available through Render.

Analytical scope and limitations.

This is a TripleTen academic portfolio project. It does not establish a causal relationship between mileage and price, build a predictive valuation model, or demonstrate a production machine-learning deployment.

Explore the work

Launch the dashboard or inspect its code

The public Streamlit application generates a mileage histogram and can optionally include a price-versus-mileage scatter plot. The application's current interface labels are in Spanish.

The reorganized GitHub project includes app.py, the EDA.ipynb exploratory notebook, the dataset, and requirements.txt.
